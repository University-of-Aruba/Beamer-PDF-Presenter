# Beamer PDF Presenter 1.2.0

Version 1.2.0 adds optional spoken narration to PDF presentations. A prepared
text script can read the lecture aloud and advance through slide reveals,
with pauses for classroom discussion. Narration uses a voice installed on the
computer and works offline.

## Features

- **Read a prepared lecture aloud.** Start narration from the current page
  with **Auto-play**. Choose a local voice and adjust its speaking speed.
  Follow the narration text privately on the dashboard.
- **Leave time for discussion.** A script can pause for a set time or wait
  until **Continue** is selected. Manual page changes stop narration;
  showing the full-screen timer or blanking the audience screen pauses it.
- **Move smoothly through reveals.** Upcoming pages are prepared in advance
  to reduce delays. Reveal captions remain silent guidance for the lecturer.
  Spoken cues in the script are read aloud.
- **Choose the Research Center logo.** The University of Aruba Research
  Center is now available in the **Brand** selector and full-screen timer.

Existing presentation controls remain available, including the private
next-page preview and virtual laser pointer. Selected PDFs and narration
scripts stay on the computer.

### Try narration

Select **Load demo** to open the included example. Expand **Voice settings
and narration text**, choose a local voice, then select **Auto-play**.

For a lecture, keep its matching text script beside the PDF. Use **Open PDF
folder**, double-click the PDF, then select **Auto-play**. A PDF opened on its
own can use **Open narration** to attach the script. The
[narration guide](https://github.com/University-of-Aruba/Beamer-PDF-Presenter/blob/v1.2.0/docs/NARRATION.md)
explains how to prepare a script. Check the chosen voice and speakers before class.

## Downloads and platform support

| Platform | How to start |
| --- | --- |
| Windows 10/11, Intel or AMD | Use the complete offline package below. |
| macOS, formerly OS X | Use the source setup below; Python 3 is required. |
| Linux | Use the source setup below; Python 3 is required. |

### Windows offline package

Download **Beamer-PDF-Presenter-1.2.0-Windows-x64-Offline.zip** from this
release's **Assets** section.

1. Right-click the ZIP and choose **Extract All**.
2. Open the extracted application folder and double-click **start-windows.bat**.
   Keep the console window open while presenting.

The package includes everything needed to run the presenter offline after
extraction. Narration uses an installed local voice available in the browser.
The launcher requests no administrator rights; an institutional computer's
security policy may require IT approval.

The **Source code** downloads require the source setup below and omit the
bundled Windows runtime.

### macOS and Linux source setup

Download and extract the source archive. With Python 3 installed, open a
terminal in the project folder and run:

```bash
python3 tools/cache_pdfjs.py
python3 serve.py
```

The first command needs internet access once to prepare the PDF viewer.
Open the local address printed by the second command. Separate portable
macOS and Linux packages are not included.
