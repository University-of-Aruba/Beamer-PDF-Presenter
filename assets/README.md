# SISSTEM branding

`sisstem-gear.png` is an unmodified copy of the supplied SISSTEM gear-and-leaf logo.

- Source: supplied University of Aruba SISSTEM course artwork.
- Source and copy SHA-256: `14f9b8ca2f0f41347129da408760827af3c10d561cb40691c5459518318526d9`
- Used in the presenter header, browser favicon, and full-screen analog countdown (including its private presenter preview).

The interface palette is derived from the supplied artwork: teal `#009ca6`, deep teal `#006b6f`, and cream `#efe4bc`. Dark teal surfaces and lighter teal `#64d6d6` adapt those colors for readable controls and text. These are application design choices based on the logo, not a verified official brand guide. Amber and red retain their countdown warning and completion meanings.
