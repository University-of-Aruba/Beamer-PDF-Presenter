# Contributing

Improvements that make PDF presentation easier for lecturers are welcome.
Use an issue to describe the teaching situation and expected behavior before
starting a large change. Small fixes can go directly to a pull request.

Follow [the development guide](docs/DEVELOPMENT.md), keep changes focused, and
include the relevant test results. For interface changes, include screenshots
of the presenter and audience views without student or confidential material.
Check keyboard use, wrapped filenames, offline behavior and the dark theme.

Do not commit course PDFs, student data, credentials, downloaded runtimes or
build output. New dependency and logo assets need their source, license and
integrity recorded. By contributing, submit original changes under the project’s
Apache 2.0 terms; retain the notices of any incorporated third-party work.
