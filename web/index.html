Windows setup in three steps

No separate Python installation is needed in the offline package. Keep the extracted folder together.

  1. Download the offline Windows ZIP.On the GitHub release page, open Assets and choose the file ending in Windows-x64-Offline.zip. The automatically generated source-code files are for developers.
  2. Right-click → Extract All.Save it in Documents or another normal local folder.
  3. Open the folder and run start-windows.bat.Keep its small console window open while presenting. Select Open PDF, then Open audience window.

Use the material you already teach

Export slides from PowerPoint, Keynote or Google Slides as PDF, or open an existing document. Beamer overlays work as separate PDF pages. PDF conversion removes animations, video and PowerPoint speaker notes.

On macOS or Linux, use the browser demo, or follow the source setup in the project README. The app requests no administrator rights, but managed-computer policies can still restrict local applications.
